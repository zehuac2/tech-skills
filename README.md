# Developer Guide

This repository contains skills for Claude and OpenAI Codex.

## Setup

Install Bun before you set up the repository.

After cloning, run `bun install` to install dependencies.

Then run `bun run config` to configure Vite+ and enable Git hooks.

## Formatting and Checks

Run `bun format` to format the repository.

Run `bun check` to check formatting and lint rules.
